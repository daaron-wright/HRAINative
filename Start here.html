Contract-to-Capacity: workshop kit

Everything to run the two days: slides, a facilitator guide, printed materials and a phone voting tool. Every session has three ways to run it, so your team can shape the experience.

Before a deal is signed, we know whether we can staff it. If we cannot, a named person owns the gap.

Get ready in five steps

  1. Choose an option for each sessionOpen the facilitator guide, Plan tab. The recommended mix is already selected, and the deck is already set up for it. Change any session; the run sheet, materials and slide list update.
  2. Show or hide slides, only if you changed the mixThe guide lists which slides to show and which to hide. In PowerPoint: Slide Sorter, select them, right-click, Hide Slide. The Hub slide still jumps anywhere.
  3. Print the kitPrint only the packs your options need. The guide's Print kit tab says what each item is for and how many.
  4. Test the room tool on the venue Wi-FiThe day before, start it on the presenting laptop and join from two phones. The room tool's README has plan B, C and D if phones cannot connect.
  5. Optional: screenshots of the working versionSlides 105, 122 and 129 read well as they are. The build team can paste a screenshot on each on the day.
